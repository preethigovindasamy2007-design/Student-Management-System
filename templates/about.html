Project Overview

College Mini Project

The Student Management System (SMS) is a lightweight, responsive web application designed for academic departments to streamline student administration. It provides a centralized dashboard to register students, record marks, monitor attendance, evaluate holistic academic performance, and generate printable institutional reports.

Frontend
HTML5 + CSS3 + Vanilla JS
Zero heavy frameworks
Backend
Python Flask 3
Clean MVC routing
Database
SQLite 3
Relational schema with FKs
Analytics
Chart.js CDN
Dynamic data visualization

System Architecture

1. Presentation Layer (Client): Built using semantic HTML5, custom responsive Vanilla CSS3, and JavaScript (ES6+). Includes Chart.js for data visualization.

2. Application Layer (Server): Python Flask server exposing standard RESTful routing and API endpoints. Processes forms, computes grades, validates constraints, and serves templates.

3. Persistence Layer (Database): SQLite relational database (database/student_management.db) with foreign key cascading and indices.

Database Schema Overview

  • departments: department_id (PK), department_name
  • students: student_id (PK), name, email (UNIQUE), phone, gender, dob, department (FK), year, section, address, admission_year, created_at
  • marks: mark_id (PK Auto), student_id (FK), subject, internal_mark, external_mark, total_mark, grade
  • attendance: attendance_id (PK Auto), student_id (FK), total_days, present_days, absent_days, attendance_percentage

Key Project Highlights for Viva Voce & Presentation

Viva Preparation
Q: Why SQLite instead of MySQL or MongoDB?

SQLite is serverless, zero-configuration, and stores data in a single cross-platform file. Perfect for college mini projects and desktop/local deployment.

Q: How is Academic Performance computed?

Dynamically aggregates all subject marks for a student, checks total percentage, and correlates it with attendance records to classify the student into Excellent, Good, Average, or Needs Improvement.

Q: How are duplicates prevented?

Database unique constraints on student_id and email plus server-side validation checks in Flask prevent duplicate records and return user-friendly flash messages.
